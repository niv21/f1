# Birthday Grand Prix 🏎️

Мини-аркада в стилистике Формулы-1: один заезд, на финише — поздравление
**Happy Birthday, Alexander Savchenko! Happy 35!** и конфетти.

**Играть онлайн:** https://niv21.github.io/f1/

## Запуск

Проще всего — открыть `index.html` двойным кликом: игра целиком в одном файле,
без зависимостей и сборки, работает офлайн.

Либо через локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Режимы

Выбираются на стартовом экране, выбор запоминается в браузере. Поздравление,
«35» и конфетти показываются на финише в любом режиме.

| Режим | Для кого | Что меняется |
|---|---|---|
| **Birthday** | именинник | Медленные соперники и сильная подкрутка — победа практически гарантирована; мягкий штраф за траву |
| **Grand Prix** | обычный заезд | Честный баланс, лёгкая подкрутка, чтобы борьба не разваливалась |
| **Pro** | тем, кто хочет челленджа | Быстрые соперники, никакой подкрутки, жёсткий штраф за траву и сильнее сносит в поворотах |

## Звук

Синтезируется на лету через WebAudio — никаких файлов, игра остаётся одним
офлайн-файлом: гул двигателя с тоном от скорости, шуршание на траве, стартовые
огни, фанфары на финише. Кнопка **♪** сверху выключает звук, выбор запоминается.

## Управление

| Действие | Клавиатура | Телефон |
|---|---|---|
| Газ | `↑` / `W` | кнопка **GAS** |
| Тормоз | `↓` / `S` | кнопка **BRAKE** |
| Руль | `←` `→` / `A` `D` | кнопки **‹** **›** |
| Старт / рестарт | `Space` | тап по кнопке |

## Как устроено

- `index.html` — вся игра: разметка, стили и логика в одном файле.
- Рендер — Canvas 2D, псевдо-3D дорога (проекция дорожных сегментов), болиды
  рисуются кодом, внешних картинок и шрифтов нет.
- Трасса: прямые, шиканы, две шпильки, подъёмы и спуски; старт по огням F1,
  финиш — шахматная клетка, дальше праздничный экран с конфетти.

## Отладка

- `index.html?fast=1` — укороченная трасса (несколько секунд), чтобы быстро
  проверить финишный экран.
- `index.html?mode=party|race|pro` — запуск сразу в нужном режиме, минуя выбор
  на стартовом экране.
